### 👋 About Me

I'm a **freelance Software Engineer** who builds and maintains systems that **can't afford to fail**: backends that handle billing, bots that talk to customers in production, and Docker containers that self-heal when something breaks at 3 AM.

I work end to end: I design the database, write the API, build the frontend that consumes it, and then stick around to make sure it keeps running — because a system that "works on my machine" isn't good enough. It has to work in production, unattended.

> 🔒 Most of my repositories are **private** (client projects running in production). This profile summarizes the stack and the kind of work I do day to day.
